# بوت حفظ اللغة العربية

بوت تيليغرام مخصص للعربي فقط، مبني على نوطة **أمية اللغة العربية – السنة الأولى**.

## الميزات
- 107 أسئلة وبطاقات من النوطة.
- تسميع كتابي مع مقارنة عناصر الجواب الأساسية.
- حل على الورقة ثم عرض جواب نموذجي وتقييم ذاتي.
- أكمل الفراغ.
- دراسة حسب القسم.
- امتحان تجريبي من 10 أسئلة.
- مراجعة تلقائية للأسئلة الضعيفة.
- إحصاءات مستوى الحفظ.
- تسجيل المستخدمين وعرضهم للأدمن عبر `/users`.
- تخزين دائم عبر PostgreSQL/Neon.

## الملفات المطلوبة على GitHub
- `bot.py`
- `arabic_bank.json`
- `requirements.txt`
- `render.yaml`
- `README.md` اختياري

لا تحتاج إلى `questions.json` لأن هذه النسخة للعربي فقط.

## متغيرات Render
- `BOT_TOKEN`: توكن BotFather.
- `ADMIN_IDS`: رقم حساب الأدمن، ويمكن وضع أكثر من رقم مفصولاً بفاصلة.
- `DATABASE_URL`: رابط Neon لحفظ المستخدمين والتقدم بشكل دائم.
- `WEBHOOK_SECRET`: اختياري، ويقبل الحروف والأرقام و `_` و `-` فقط.
