# بوت مهارات الحاسوب — نسخة Telegram Quiz Poll

هذه النسخة تحتوي **415 سؤالاً** وتضيف نمطاً جديداً يعرض الأسئلة على شكل **Telegram Quiz Poll** مثل الصورة، مع بقاء الاختبار العادي القديم.

## المزايا الجديدة

- زر: **📊 كويز تيليغرام — مثل الصورة**.
- كويز سريع 10 أسئلة.
- كويز شامل 40 سؤالاً.
- كويز حسب القسم حتى 20 سؤالاً.
- كويز صح أو غلط 15 سؤالاً.
- ترتيب الأسئلة والخيارات عشوائي.
- ينتقل تلقائياً للسؤال التالي بعد الإجابة.
- يحسب النتيجة ويحفظها ضمن الإحصاءات.
- زر لإنهاء الكويز، إضافة إلى الأمر `/cancel`.
- يتجاهل `WEBHOOK_SECRET` غير الصالح بدل توقف الخدمة.

> الاستبيان غير مجهول لأن البوت يحتاج معرفة إجابة المستخدم لحساب علامته وإرسال السؤال التالي.

## التحديث من الهاتف

إذا كان البوت موجوداً على GitHub مسبقاً:

1. افتح مستودع البوت على GitHub.
2. افتح الملف `bot.py`.
3. احذف الملف القديم أو استخدم **Upload files** وارفع `bot.py` الجديد مع اختيار الاستبدال.
4. اضغط **Commit changes**.
5. انتظر نشر Render تلقائياً، أو اختر: **Manual Deploy → Deploy latest commit**.
6. بعد ظهور الحالة **Live** افتح البوت وأرسل `/start`.
7. اضغط **📊 كويز تيليغرام — مثل الصورة**.

لا تحتاج لتغيير `questions.json` إذا كنت قد رفعت نسخة الـ415 سؤالاً سابقاً.
