# بوت مهارات الحاسوب — نسخة الهاتف

ملفات التشغيل الضرورية فقط. ارفع الملفات الخمسة إلى جذر مستودع GitHub، ثم أنشئ Blueprint على Render من ملف `render.yaml`.

بعد التشغيل:
1. أرسل `/start` للبوت.
2. أرسل `/id` وخذ رقمك.
3. في Render > Environment أضف `ADMIN_IDS` بقيمة رقمك، ثم احفظ ليُعاد النشر.

لا ترفع توكن البوت إلى GitHub؛ ضعه فقط في متغير البيئة `BOT_TOKEN` داخل Render.
